# 短内容会话策略引擎

该服务为多租户内容平台提供版本化的观看策略和会话执行能力。策略可以限制年龄、每日用量、单次时长与休息时段；会话在启动时固定策略版本，心跳按顺序结算观看时长，并把每日用量、事件发件箱和操作记录保存在 SQLite 中。监护授权、策略灰度、限制申诉和合规暂停模块共享可审计的状态变更规则。

## 限制决定申诉

用户对年龄、休息时段或每日额度的拒绝决定提出申诉时，`/v1/appeals` 提供完整的处理流程：立案（`POST /v1/appeals`，固定拒绝决定、策略版本、会话与证据，同一拒绝事件只能立一案）、认领（`POST /v1/appeals/{id}/claim`，并发下只有一个客服成功）、补证（`POST /v1/appeals/{id}/evidence`）、裁决（`POST /v1/appeals/{id}/adjudicate`，一次性：维持原决定、纠正资料或发放有期限的例外，且不得篡改历史使用量）、复开（`POST /v1/appeals/{id}/reopen`）与解释（`GET /v1/appeals/{id}`，返回立案时固定的策略轨迹、证据与时间线）。客服操作需携带 `X-Agent-ID` 头，裁决仅限认领人执行；例外按（租户, 用户, 限制类型）生效并在到期后自动失效。

## 运行方式

安装项目依赖后执行 `uvicorn spe.app:app --host 127.0.0.1 --port 8000`。默认数据库为当前目录的 `spe.db`，不需要额外服务。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q spe tests
```

自动化测试覆盖策略校验、版本固定、会话幂等、并发启动、乱序心跳、跨午夜结算、额度截断、进程重启后的状态恢复，以及申诉的重复立案、并发认领、权限隔离与例外到期。
